## ⚙️ Getting Started

Follow these steps to explore the project on your local machine.

### 1. Clone the repository

```bash
git clone https://github.com/atiyabman13/js-practice-and-project.git
```

### 2. Navigate to the project directory

```bash
cd js-practice-and-project
```

### 3. Open the project

Open the folder in Visual Studio Code:

```bash
code .
```

### 4. Run the code

- Open `index.html` in your browser to view the HTML-based project.
- For JavaScript assignments, use a browser's developer console or Node.js, depending on the code.
- If a project contains separate HTML, CSS, and JavaScript files, keep the files together so their relative paths work correctly.
